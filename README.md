# Artificial Neural Networks: interactive labs

Interactive labs for the three ANN lectures (Part II PDN, Module N3, University of Cambridge).

- `neuron-lab/`: Lecture 1, The artificial neuron
- `convolution-lab/`: Lecture 2, Vision
- `attention-lab/`: Lecture 3, Language

Each lab is a single self-contained HTML file that runs entirely in the browser; no server or installation is needed.

## Publishing with GitHub Pages

1. Upload the contents of this folder to the root of a public repository.
2. In the repository, open Settings, then Pages. Under "Build and deployment", choose "Deploy from a branch", select `main` and `/ (root)`, and save.
3. After a minute or two the site is live at `https://<username>.github.io/<repository>/`.
